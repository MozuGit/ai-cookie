## [ 02 ] // 本地运行

环境 // Node.js 20.19+ 或 22.12+

```bash
# 1. 获取源码
git clone https://github.com/MozuGit/ai-cookie.git
cd ai-cookie

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

开发地址 // `http://localhost:5173/`

构建静态产物

```bash
npm run build
npm run preview
```

产物 // `dist/` | 可部署任意静态托管

> 存档 // `localStorage` | 主键 `ai-cookie.save.v1` | 清理站点数据即清空进度 | 无云同步
